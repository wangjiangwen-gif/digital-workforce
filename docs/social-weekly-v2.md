# 社媒热点周报 V2.1

初始化保持三个技能入口，版本 weekly-v2.1。现有员工再次初始化只升级技能引用，不自动覆盖用户身份和记忆；本次测试员工通过受控升级单独同步配置与方法记忆。

## 当前已实现
- prepare.py：稳定 row_id、同平台 log1p/P1/P99 标准分、原始指标保留、分层样本和质量报告。
- workflow.py：真实标注导出文件的批次/版本/哈希核验，两批 LEFT JOIN、营销筛选、八路结果类型校验、缺失和 >5% 阻塞、成本账单。
- statistics.py：E1 行业、E2 节点日历、E3 平台事件与驱动词指数/TOP10审计、E4 结构化候选。
- validate.py：V2 report/webpage 分阶段文件验收，HC1/HC2/HC3 产物哈希绑定，审核版一致性和基本静态HTML检查。保留旧V1产物兼容。

## 业务流程
取数或上传 → 小样本 C0+C3 → 营销筛选 → R1-R5+C2 → HC1 → 全量重复 → HC2 → E1-E4 → 飞书待审核 → HC3 → 回读人工删改与截图 → 网页 → 获授权妙搭发布。

## 仍需接入
DataHub MCP、hot-topics-data、客户正式八路 Prompt/28列字典、canonical-event-registry、营销节点日历、客户网页模板及妙搭发布工具/凭证。
文件模式接受真实外部导出，不生成假标注。HC1/HC2/HC3目前由 Agent 核对真实用户消息和本地文件记录；本地哈希不提供可信审批证明。没有服务端业务调度、自动补标任务提交或跨进程审批恢复。

## 需要业务确认的细节
热度标准化恒定值/null策略；E1/E2使用最高标准分的展示口径；E4平台独立候选后跨平台选稿规则。不得把平台适配字段冒称正式28列。

## 测试
`npm test` 同时运行 Python 工作流、统计及产物验证器行为测试；只使用隔离测试数据和模拟审批记录，不产生真实业务审批。
